# 基本表現Aの10記述子：承認済み定義 A-1

**状態：2026年10月20日にユーザー承認済み。以下の推奨として提示した規則・数値を定義 A-1 として実装しています。比較候補の記述は選定理由として残しています。**
目的は合意済みの10記述子を完成させることです。結合テーブル・結合推定・水素結合・内部幾何のCalculatorは対象外です。
明文化した定義・版・入力注釈・原子属性表の指紋を計算前に登録し、その定義に対応するCalculatorを実行します。

## 1. 承認された追加規則と選定理由

| 対象 | 採用規則 | 比較した候補・選定理由 |
|---|---|---|
| 二次構造の領域 | 下記の狭い角度領域による3分類。連続残基数の条件は設けない | より広い領域や最短連続長を要求する方式もあるが、局所的な「様」の分類と長さによる判定を混ぜず、単独残基の角度から定義できる方式を推す。領域の幅はMiniTopol用の案であり、普遍的標準を主張しない |
| 接触ペア | 同一残基と、確認済みの同一連続区間で配列距離1・2のペアを除外。最短重原子距離≤4.5 Å | 前後1残基だけ除外する候補もある。前後2残基の除外はMDTrajのall-contact選択と比較しやすい。異なる鎖を番号の近さで除外しない |
| 時間集計 | 全フレーム・全ての可能な始点・全時間差。フレーム差kで寄与する始点数はN−k | 長い時間差の打ち切り・始点の間引きは採用しない。長い時間差も残し、寄与数を併記する |
| SASAの半径 | Bondiのvan der Waals半径とMantinaら2009の主族元素拡張の固定表。化学種による自動変更はしない | ProtOrなど残基・原子型ベースの半径表もあるが、今回の重原子・非結合情報から定義しやすい元素表を推す。未定義元素に一律2 Åなどを自動代入しない |
| SASAの球面 | 黄金角スパイラルの決定的な960点/原子。プローブ1.4 Å | 960点はMDTrajと比較しやすい。3840点で精度依存を検証する候補とし、点数変更は定義の版に記録する。結果を見て点数を無断変更しない |
| PBCの時間復元 | 原座標維持の上、要求時だけNoJump方式。開始時の像配置が適切で、隣接保存フレーム間の移動が半ボックス未満という前提を明示 | 既に連続化された入力をそのまま使う経路も残す。結合に基づくunwrapや、初期フレームの分断を結合推定で補修する方式は使わない |
| 残基の連続性 | 信頼できる鎖・配列順序・連続区間の注釈がある範囲のみ利用する | GROの並びや残基番号の連番だけから鎖・連続性を確定しない。注釈がない角度は未定義として理由を保存する |
| 動的相互相関の位置合わせ | RMSD等と共通のCα Kabsch位置合わせを行った座標を使用 | 未位置合わせでは分子全体の並進・回転も相関へ寄与するため、今回の内部運動との整合を優先する候補 |

## 2. 原子属性・欠損・位置合わせ

- 基本表現Aの原子と順序は変更しない。全重原子を使う記述子で、半径・質量のない原子を黙って除外しない。
- Cαは元素Cかつ主鎖のCAとして一意に確認できるものを使う。カルシウムなどの原子名CAをCα扱いしない。非標準名称や同一残基内の重複は明示的な役割指定が必要。
- GROに元素は明記されない。既存Converterの推定由来は保持する。確実な属性を別途指定できる経路を設け、曖昧な原子についてCalculator側で別の推定を追加しない。
- 原子質量はMDAnalysis 2.10.0の元素質量表を版付きで固定する。C=12.011、N=14.007、O=15.999、P=30.974、S=32.06 u。明示質量を優先し、同位体・特殊な質量は明示入力とする。未知・非正質量は回転半径の計算を停止し、理由を示す。
- 位置合わせは、PBC条件を満たした座標について、初期フレームの同一Cα集合への等重みKabsch法とする。反転を許さず、同じ変換を全重原子へ適用する。Cαの数不足、対応の曖昧さ、非有限値、共線配置など回転を一意に決められない場合は、別の集合へ勝手に変更せず対象の計算を停止する。
- 全体の位置合わせ集合は全フレームで共通とし、フレームごとに欠損原子を除いた別集合へ切り替えない。
- 未定義の値はParquetのnullと理由で表す。ゼロや「その他」への置換をしない。φとψは独立に成立可否を判定し、片方だけ計算できる場合はその値を残す。
- 原座標の不正値はConverterの既存検査で拒否する。後から判明した属性の不足は該当するCalculatorの失敗として記録し、他の完成済み結果やWorkspaceを削除しない。

## 3. PBC取得の条件と使い分け

Registryから座標・距離を要求し、Calculatorは元GRO・XTCを開かない。原座標・時刻・ボックスの保存内容は変えない。

### 周期距離・局所幾何

接触の最短距離は各フレームのボックスに対する最小像距離とする。
直交および対応可能なGROMACS形式の非直交ボックスを検証し、欠損・特異・不正ボックスを周期距離へ流用しない。
Ramachandran角は、注釈で連続性を確認した主鎖原子の局所ベクトルを使用し、周期系では各局所ベクトルの最小像を使う。
局所ベクトルの最小像を一意に解釈できる長さの範囲にあることが前提であり、そこから化学結合を認定したり結合テーブルを生成したりしない。

### 時間方向の連続座標

NoJumpはKulke–Vermaas 2022、非直交系の式B6に基づく分率座標での連続化とし、逐次状態をチャンク境界を越えて引き継ぐ。
全フレームのボックスが必要。隣接する保存フレーム間の真の移動が半ボックス以上の場合、wrapped座標だけから正しい経路を一意に復元できない。
この前提は観測されたwrapped座標だけから保証できないため、入力の前提条件として明示する。

NoJumpは初期フレームの像を出発点にする。初期フレームですでに対象分子・複合体が別の像へ分断されている場合、結合なしで自動修復できるとは扱わない。
対象を意図した像にまとめた初期配置が必要であり、不明なら補正済みとせず該当計算の不可理由を示す。
既に連続化された座標、または非周期入力を明示指定して使う経路も用意する。周期ボックス欠損から非周期入力と推測することはしない。

RMSD・RMSF・MSD・時間相関・動的相互相関は、この条件を満たした座標に共通の位置合わせを行う。
回転半径とSASAは、同じ条件で対象Aの意図した像配置を得た座標を使う。SASAはAを単一の解析対象集合として計算し、周期複製体を追加の遮蔽物にはしない。
周期複製体との遮蔽を含める定義は別候補だが、今回は採用しない。

## 4. 時間差と数学的定義

以下では、Nは全フレーム数、MはAの全重原子数、x_i(t)は補正・位置合わせ後の原子iの座標、u_r(t)はCα残基rの時間平均位置からの変位とする。
計算はfloat64で集計する。分散の分母はNとし、標本分散のN−1にはしない。
解析区間は初期フレームを含む全トラジェクトリとする。

### フレームごとのRMSD

RMSD(t) = sqrt(sum_i ||x_i(t) − x_i(0)||² / M)。単位Å。

### 原子ごとのRMSF

平均位置mean_i = sum_t x_i(t)/N。
RMSF_i = sqrt(sum_t ||x_i(t) − mean_i||²/N)。単位Å。
Welford法などの逐次集計で、チャンク内平均だけを別々の結果として扱わない。

### MSD

MSD(k) = sum_{t=0}^{N-k-1} sum_i ||x_i(t+k) − x_i(t)||² / (M(N−k))。
k=0,...,N−1の全時間差を残し、k=0は0。単位Å²。始点数N−kと対象原子数を保存する。
時間方向のブロックを独立軌跡と見なさず、チャンクをまたぐ組も全て数える。

### 時間自己相関

variance_r = sum_t ||u_r(t)||²/N。
C_r(k) = [sum_{t=0}^{N-k-1} u_r(t)·u_r(t+k)/(N−k)]/variance_r。
k=0,...,N−1。正の分散ではC_r(0)=1、分散0では全時間差null。無次元。
全区間の同じ平均位置を使い、時間差ごと・チャンクごとに平均を取り直さない。

### 動的相互相関

D(r,s) = [sum_t u_r(t)·u_s(t)/N]/sqrt(variance_r variance_s)。無次元。
異なる残基の一意な組r<sを対象とし、対角成分は出力対象に含めない。
いずれかの分散が0ならnull。残基ペアごとに全フレームを集計し、残基ブロックを使って全相関行列のRAM展開を避ける。

### 時刻

時刻はps、角度はdegreeで保存する。
全時間差を単一の物理時間差へ対応させるMSD・時間相関は、等間隔の正順な時刻を確認できる入力を対象とする。
確認にはXTC時刻のfloat32丸めを考慮した許容誤差を定義へ保存する。許容誤差は時刻直線t(0)+kΔtに対し、max(10^-6 ps, 4 eps_float32 max|t|)以内とする。
Δtは最初と最後の時刻から求め、重複・逆行時刻を認めない。確認できない入力は間引きや再サンプリングをせず、当該2記述子が未対応となる理由を示す。
他の記述子と、元時刻・元フレームの保存はその理由で省略しない。
不等間隔の時刻については実時間差の集約・区間分けの定義が別途必要であり、等間隔と見なして混ぜない。

全時間差FFTと逐次・ブロック処理のいずれを使っても同じ式を実装する。
メモリが不足する場合には作業用ディスクへ必要な座標・中間量を分割保存し、全フレーム×全原子をRAMへ同時に載せない。
FFTの一時配列も読み出す原子・残基数を制御する。直接計算の検証値と照合する。

## 5. SASA・回転半径・主鎖角・二次構造・接触

### SASA

採用半径の代表値はC=1.70、N=1.55、O=1.52、P=1.80、S=1.80 Å。実装時に参照表全体と出典・版を保存する。
元素別van der Waals半径へプローブ1.4 Åを加え、960点のうち他の重原子球に遮られない点の割合×4π(半径+1.4)²を原子SASAとする。
水素は球・遮蔽物のどちらにも追加しない。未掲載元素は、半径の明示指定がない限りSASAを停止し理由を示す。
原子値の和を残基値、さらに全Aの和を全体値として保存する。全てÅ²。
960点による表面積近似には方向依存の離散化誤差がある。3840点との比較を精度検証に含める。
SASAのために一律のCα位置合わせを追加せず、元の向きで計算する。

### 回転半径

重心c(t)=sum_i m_i x_i(t)/sum_i m_i。
Rg(t)=sqrt(sum_i m_i||x_i(t)−c(t)||²/sum_i m_i)。単位Å。
原子を等重み化せず、使用質量と出典を保存する。

### Ramachandran

φ(i)はC(i−1), N(i), CA(i), C(i)、ψ(i)はN(i), CA(i), C(i), N(i+1)の符号付き二面角。
角度は[-180°,180°)に正規化する。
信頼できる同一鎖・連続区間の注釈と、一意な必要原子が揃う場合のみ計算する。
原子欠損・重複、退化した幾何、連続性不明、末端で未定義の側はnullと理由を保存する。
残基番号が連番という理由だけで連続性を認定せず、距離から化学結合を推定しない。

### 二次構造の採用領域

- ヘリックス様：−100°≤φ≤−30°かつ−80°≤ψ≤−5°。
- 伸展様：−180°≤φ≤−90°かつ、90°≤ψ<180°または−180°≤ψ≤−150°。
- その他：有効なφ・ψが上記どちらにも入らない。
- 未定義：φまたはψがnull。3分類へ強制的に割り当てない。

単独残基でも角度が入れば分類し、3残基以上などの最短連続長や時系列の平滑化を加えない。
より広い領域を使う候補や連続長を要求する候補もあるが、現案は単純な局所領域分類として明示する。
Ramachandranと同じ角度計算を共用する。水素結合・DSSP・結合テーブルは用いない。

### 接触マップ

全Aの残基を対象とし、同一残基を除く一意な組i<jについて最短重原子距離≤4.5 Åを接触とする。
確認済みの同一連続区間で配列距離≤2の組を除外する。異なる鎖・異なる連続区間・非ポリマー間では番号の差から除外しない。
注釈がなく除外対象の近接残基を確定できない場合、指定の除外規則を適用できない理由を報告し、別の規則へ自動変更しない。
各フレームは接触した組と距離を疎に保存する。頻度は全Nフレームを分母にし、接触フレーム数も保存する。
一度も接触しない対象ペアは頻度表の行を省略し、対象ペアの定義と分母Nから0と復元できるようにする。
除外ペアを「接触頻度0」と混同せず、対象外として識別する。

## 6. 実装・保存方針

フレーム型はRMSD、SASA、Ramachandran、回転半径、二次構造、接触状態。
集計型はRMSF、MSD、時間相関、動的相互相関、接触頻度。
原子、残基、ペア、時間差、全体の異なる粒度をそれぞれの出力列で区別し、全記述子を単一のフレーム別スカラーへ押し込めない。
大きなペア・時間差の出力は分割Parquetと完了記録で管理する。部分出力を全区間の完成結果として公開しない。
既存の正常なConverter・Registry・Resultsを維持しつつ、定義登録・逐次集計・全時間差FFT・分割出力管理を追加している。

## 7. 根拠として確認した一次資料

- [MDTraj Shrake–Rupley API](https://mdtraj.readthedocs.io/en/latest/api/generated/mdtraj.shrake_rupley.html)：プローブ、960点、原子・残基の出力。
- [MDTraj SASA実装](https://mdtraj.readthedocs.io/en/latest/_modules/mdtraj/geometry/sasa.html)：黄金角スパイラル、半径表、Bondi/Mantina等の出典。実装には元素によるイオン半径の置換や2 Åの代入があるため、半径表全体を無条件には採用しない。
- [Mantina et al., 2009](https://pubmed.ncbi.nlm.nih.gov/19382751/) / [著者研究室の解説](https://comp.chem.umn.edu/netstep/2009/May/vdWradii.html)：Bondiと整合させた主族元素のvan der Waals半径。
- [FreeSASA Classifier](https://freesasa.github.io/doxygen/group__classifier.html)：比較候補となるProtOr等の半径分類。
- [MDTraj contacts API](https://mdtraj.readthedocs.io/en/latest/api/generated/mdtraj.compute_contacts.html)：closest-heavy、最小像距離、配列距離1・2の除外。
- [MDAnalysis NoJump](https://docs.mdanalysis.org/stable/documentation_pages/transformations/nojump.html)：Kulke–Vermaas法、非直交系、時系列順序、初期配置と半ボックス移動の前提。
- [Kulke and Vermaas, 2022](https://doi.org/10.1021/acs.jctc.2c00327)：時間方向の可逆的連続化。
- [MDAnalysis MSD](https://docs.mdanalysis.org/stable/documentation_pages/analysis/msd.html) / [GROMACS correlation functions](https://manual.gromacs.org/current/reference-manual/analysis/correlation-function.html)：時間始点の平均、FFTと直接計算の関係。
- [MDAnalysis 2.10.0質量表](https://docs.mdanalysis.org/2.10.0/documentation_pages/topology/tables.html)：固定質量の候補。
- [Barlow and Thornton, 1988](https://pubmed.ncbi.nlm.nih.gov/3418712/)：実構造におけるヘリックス角度の分布。上記の矩形境界そのものが論文の標準定義という意味ではない。
