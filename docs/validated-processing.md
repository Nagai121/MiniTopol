# 検証済み処理経路の統合

main `40f46f5`を起点に、候補`x12-03`の製品コードを移植しています。実験driver、取得済み試料、出力Workspace、ログ、測定キャッシュは配布物に含めません。座標走査の統合など、追加の最適化や大規模な再構成は行いません。

変更はAGX1による可逆A保存、整数SASA counts、検証付きRamachandran recipe、GPU stage待機中の独立CPU処理、厳密Contacts kernelと順序付き有限window、整列とMSD中間状態の削減です。A-1の全原子・全フレーム・SASA960点・半径とprobe・全ラグ・null/reason・TPR結合の定義を維持します。

元候補の固定11試料（170,011フレーム、118,476,201 atom-frames）の単回観測は178.925653秒、完成Workspace合計884,882,429 bytesです。先行候補179.706085秒との差は約0.78秒で、安定した性能優位や一般的な速度保証を示しません。キャッシュ、競合、機種、依存バージョンが異なる実行時間は保証していません。GBは10億bytesです。

元候補では全Aの座標・時刻・boxビットと全10指標の全値・null/reason・科学メタデータ・結合・DB・MCPを照合しました。6独立WorkspaceでSASA確定、Contacts計算中、Contacts初回公開の強制プロセス終了とpeer完了、未完了だけの再開、完成パートのSHA/mtime不変、冪等性を検証しています。変更のない境界についてはソースhashと呼び出し契約を照合して以前の検証を再利用しています。物理停電やSSD制御装置の耐久性試験ではありません。

Ramachandranの全量読み出しはAから再計算してhash照合するためCPU費用があります。元環境では全11試料の論理読み出しと比較に約60秒、PTBの代表例で約7.9秒でした。これは初回生成時間の外です。生成を計算省略によって速くしたものではありません。

統合先でも固定11試料を新規生成し、immutableな参照Parquetに対する全Aビット・全10指標の全値とメタデータ・TPR結合・DB・MCPを再照合しました。これは科学QAであり、性能再測定には使用していません。統合先自身の6並列強制終了・peer完了・未完了のみ再開・確定済みSHA/mtime不変・冪等性も通過しています。

回帰テストにはcodec全ビット往復・改竄拒否・Numbaなしのcount保存・Contacts終了時のthread回収・64原子境界のMSD再開を含めます。ローカルの検品環境はWindows/Python 3.12です。最低依存Zarr 3.1.3/numcodecs 0.16.3の実配列往復も同じPythonで確認しています。Linux/Python 3.11を含むGitHub Actionsの実行結果を示すものではありません。

ソースまたは実行環境が異なるrecipeを無条件に引き継がないでください。旧版との途中状態互換や既存Workspaceの形式移行は対象外です。形式上の制約は[schema](schema.md)、利用方法は[calculators](calculators.md)を参照してください。
